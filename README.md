# せかいのことば(語学アプリ)

いろんな国のことばを「何語か分かる・なんとなく読める・かんたんなことなら言える」くらいまで学ぶ、スマホ向けWebアプリ(PWA)。1つのアプリに言語を足していく作り。最初は韓国語。

- 公開URL: https://kamedono213.github.io/sekai-kotoba/

## 韓国語の中身
- 文字: ハングルのしくみ → 基本の母音10 → 基本の子音14 → 文字の組み立て(反切表140字) → 濃音5(가・카・까の聞きくらべつき) → 組み合わせの母音11 → パッチム7
- 単語: あいさつ・数字・家族・食べもの・体・動物と色・日本語と似てる言葉・場所(89語)
- 文: 自己しょうかい・お店と旅行・友だちと(23文)。分かち書きのかたまりごとに意味つき
- クイズ(10問): 見て音を選ぶ/聞いて選ぶ/意味から選ぶ/子音と母音で組み立てる/ならべかえ
- 覚えぐあいの箱(ほしぞらドリルと同じ): 正解で 1→2→4→7→15日後にまた出る。まちがえると翌日。箱3以上を「覚えた」。「今日の復習」で時期が来た問題をまとめて出す

## 音声
- 読み上げ: ブラウザの speechSynthesis(端末に入っている声)。音声ファイルは持たない。韓国語の声がない端末では、メニューに追加方法の案内が出る
- 単独の子音・母音は、ㅏ や ㅇ と組んだ音で読む(ㄱ → 가、ㅓ → 어)
- 発音チェック(🎤): 音声認識(SpeechRecognition)が使えるブラウザだけ表示。聞き取った文字が正解と同じなら「ばっちり」

## データ
- `app/data/<言語>.js` が `window.LANGS` に言語を1つ登録する。言語を足すときは同じ形のファイルを作り、`app/index.html` に `<script>` を1行足す
- 項目: `t` 表示 / `say` 読み上げる文字 / `kana` 近いカタカナ / `rom` ローマ字 / `ja` 意味 / `note` ひとこと / `snd` 同じ音の目印(同じ snd は選択肢に並べない。例: ㅐ と ㅔ)
- カタカナは目安。ことばの途中で濁る音(가세요 → ガセヨ)や、つながって読む音(맛있어요 → マシッソヨ)は、読みどおりに書いている

## 作り方
- `node tools/make-icons.js` … アイコン
- `node tools/build-pages.js` … `docs/` にPWA版(GitHub Pages用)
- `node serve.js docs` … http://localhost:5398 で確認
